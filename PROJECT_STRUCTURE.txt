🎯 核心功能模块
================================================================================

1. 用户管理 (User)
   ├── 创建用户
   ├── 获取描述
   └── 成年判断

2. 数学计算 (math)
   ├── fibonacci(n)      - 斐波那契数列
   ├── is_prime(n)       - 质数判断
   └── factorial(n)      - 阶乘计算

3. 字符串处理 (text)
   ├── reverse(s)        - 字符串反转
   ├── word_count(s)     - 单词统计
   └── capitalize_words(s) - 首字母大写

4. 批量处理 (Python 特有)
   ├── fibonacci_batch   - 批量斐波那契计算
   └── filter_primes     - 过滤质数

🚀 快速命令
================================================================================

# 项目设置
./scripts/setup.sh          # 自动设置
make install                # 安装依赖
make dev                    # 开发模式安装

# 开发
cargo test                  # Rust 测试
pytest tests/               # Python 测试
make test                   # 所有测试

# 示例
cargo run --example rust_only_example    # Rust 示例
python examples/python_example.py        # Python 示例
python scripts/benchmark.py              # 性能测试

# 构建
cargo build --release       # Rust 构建
maturin build --release     # Python 构建
make build                  # 完整构建

# 发布
cargo publish               # 发布到 crates.io
maturin publish             # 发布到 PyPI

# 其他
make help                   # 查看所有命令
cargo doc --open            # 打开 Rust 文档
make clean                  # 清理构建文件
