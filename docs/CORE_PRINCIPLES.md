## 1. 所有权 (Ownership) 底层原理

### 1.1 核心概念

**所有权是 Rust 内存管理的基石，在编译期保证内存安全。**

#### 三大规则
1. 每个值都有一个所有者（变量）
2. 值在任一时刻只能有一个所有者
3. 当所有者离开作用域，值被丢弃（调用 Drop）

### 1.2 内存布局

#### 栈上数据 (Stack)
```
栈内存（从高地址向低地址增长）
┌─────────────┐ ← 高地址
│   变量 c    │
│   bool: 1B  │
├─────────────┤
│   变量 b    │
│   f64: 8B   │
├─────────────┤
│   变量 a    │
│   i32: 4B   │
└─────────────┘ ← 低地址（栈顶）

特点：
- 固定大小
- 快速分配/释放（只需移动栈指针）
- 自动管理（作用域结束自动清理）
- Copy trait 类型存储在栈上
```

#### 堆上数据 (Heap)
```rust
let s = String::from("hello");
```

**栈上的 String 结构：**
```
栈 (Stack)               堆 (Heap)
┌──────────┐            ┌───┬───┬───┬───┬───┐
│ ptr      │─────────>  │ h │ e │ l │ l │ o │
├──────────┤            └───┴───┴───┴───┴───┘
│ len = 5  │            ↑
├──────────┤            │
│ cap = 5  │            分配的内存区域
└──────────┘

String 在栈上占用：
- ptr: 8 字节（64位系统）
- len: 8 字节
- capacity: 8 字节
总共：24 字节
```

### 1.3 所有权转移（Move）

```rust
let s1 = String::from("hello");
let s2 = s1;  // 移动发生
```

**内存变化：**
```
移动前：
栈                    堆
s1 ┌────┐           ┌─────────┐
   │ptr │────────>  │ "hello" │
   ├────┤           └─────────┘
   │len │
   ├────┤
   │cap │
   └────┘

移动后：
栈                    堆
s1 ┌────┐ ❌ 无效    ┌─────────┐
   │    │           │ "hello" │
   └────┘           └─────────┘
                      ↑
s2 ┌────┐            │
   │ptr │────────────┘
   ├────┤
   │len │
   ├────┤
   │cap │
   └────┘

关键点：
1. 只复制栈上的指针、长度、容量（浅拷贝）
2. 不复制堆上的数据
3. s1 被标记为无效（编译器禁止使用）
4. 避免了双重释放（double free）
```

### 1.4 克隆（Clone）

```rust
let s1 = String::from("hello");
let s2 = s1.clone();  // 深拷贝
```

**内存变化：**
```
栈                    堆
s1 ┌────┐           ┌─────────┐
   │ptr │────────>  │ "hello" │
   ├────┤           └─────────┘
   │len │
   ├────┤
   │cap │
   └────┘
                     ┌─────────┐
s2 ┌────┐           │ "hello" │ ← 新分配的内存
   │ptr │────────>  └─────────┘
   ├────┤
   │len │
   ├────┤
   │cap │
   └────┘

特点：
- 完整的深拷贝（堆数据也被复制）
- 两个独立的内存区域
- 更昂贵的操作
- 两个变量都有效
```

### 1.5 Copy trait

```rust
let x = 5;
let y = x;  // Copy，不是 Move
```

**Copy 类型的内存：**
```
栈
┌────────┐
│ x = 5  │  原始值
├────────┤
│ y = 5  │  复制的值
└────────┘

Copy 类型（完全在栈上）：
- 所有整数类型：i8, i16, i32, i64, i128, u8-u128, isize, usize
- 浮点类型：f32, f64
- 布尔类型：bool
- 字符类型：char
- 元组（如果所有元素都是 Copy）
- 固定大小数组（如果元素是 Copy）

不能实现 Copy 的类型：
- 实现了 Drop trait 的类型
- 包含非 Copy 类型的结构体
```

### 1.6 Drop trait 与 RAII

```rust
struct MyString {
    data: *mut u8,
    len: usize,
}

impl Drop for MyString {
    fn drop(&mut self) {
        // 释放堆内存
        unsafe {
            std::alloc::dealloc(
                self.data,
                Layout::from_size_align(self.len, 1).unwrap()
            );
        }
    }
}
```

**Drop 调用时机：**
```
{
    let s = String::from("hello");
    // ... 使用 s
} // ← 这里自动调用 s.drop()

调用顺序：
1. 变量离开作用域
2. 编译器插入 drop 调用
3. 执行清理代码
4. 释放栈内存
```

## 2. 借用 (Borrowing) 底层原理

### 2.1 核心概念

**借用是创建引用而不转移所有权的机制。**

#### 借用规则
1. 在任意时刻，要么只有一个可变引用，要么有任意数量的不可变引用
2. 引用必须总是有效的（不能悬垂）

### 2.2 不可变引用 (&T)

```rust
let s = String::from("hello");
let r = &s;
```

**内存布局：**
```
栈                    堆
s  ┌────┐           ┌─────────┐
   │ptr │────────>  │ "hello" │
   ├────┤           └─────────┘
   │len │              ↑
   ├────┤              │
   │cap │              │
   └────┘              │
                       │
r  ┌────┐              │
   │ptr │──────────────┘ 指向 String 的指针
   └────┘

不可变引用 &T：
- 只占用一个指针大小（8字节，64位系统）
- 只读访问
- 可以有多个不可变引用
- 不能修改数据
- 不拥有数据（不负责释放）
```

### 2.3 可变引用 (&mut T)

```rust
let mut s = String::from("hello");
let r = &mut s;
```

**内存布局：**
```
栈                    堆
s  ┌────┐           ┌─────────┐
   │ptr │────────>  │ "hello" │
   ├────┤           └─────────┘
   │len │              ↑
   ├────┤              │
   │cap │              │
   └────┘              │
                       │
r  ┌────┐              │
   │ptr │──────────────┘ 独占指针
   └────┘

可变引用 &mut T：
- 只占用一个指针大小（8字节）
- 读写访问
- 同时只能有一个可变引用
- 可以修改数据
- 不拥有数据
```

### 2.4 借用检查器 (Borrow Checker)

**编译时分析：**

```rust
fn main() {
    let mut s = String::from("hello");
    
    let r1 = &s;      // 不可变借用开始
    let r2 = &s;      // OK：多个不可变借用
    println!("{} {}", r1, r2);
    // r1, r2 作用域结束
    
    let r3 = &mut s;  // OK：可变借用开始
    r3.push_str(" world");
    // r3 作用域结束
}
```

**借用检查器的工作：**
```
生命周期分析（编译时）：
┌─────────────────────────────┐
│ s 的生命周期                 │
│ ┌─────────────────────┐     │
│ │ r1 的生命周期        │     │
│ │ ┌─────────────┐     │     │
│ │ │ r2 的生命周期│     │     │
│ │ └─────────────┘     │     │
│ └─────────────────────┘     │
│     ┌───────────────┐       │
│     │ r3 的生命周期  │       │
│     └───────────────┘       │
└─────────────────────────────┘

检查规则：
✓ r1 和 r2 可以共存（都是不可变）
✓ r3 出现时 r1、r2 已经结束
✗ 如果 r1、r2 和 r3 重叠 → 编译错误
```

### 2.5 非词法作用域生命周期 (NLL)

**Rust 2018 引入的智能分析：**

```rust
let mut s = String::from("hello");

let r1 = &s;
let r2 = &s;
println!("{} {}", r1, r2);
// r1, r2 最后一次使用 ↑

let r3 = &mut s;  // OK：r1、r2 不再使用
r3.push_str(" world");
```

**NLL 分析：**
```
传统作用域分析（旧版本）：
{
    let r1 = &s;     // r1 作用域开始
    let r2 = &s;     // r2 作用域开始
    println!("{}");  
    let r3 = &mut s; // ❌ 错误：r1、r2 还在作用域内
}                    // r1、r2 作用域结束

NLL 分析（新版本）：
{
    let r1 = &s;     // r1 生命周期开始
    let r2 = &s;     // r2 生命周期开始
    println!("{}");  // r1、r2 最后使用
                     // r1、r2 生命周期结束
    let r3 = &mut s; // ✓ OK：r1、r2 生命周期已结束
}

关键：生命周期由最后使用位置决定，而非作用域
```

### 2.6 内部可变性 (Interior Mutability)

```rust
use std::cell::RefCell;

let data = RefCell::new(5);
let r1 = data.borrow();      // 运行时借用检查
let r2 = data.borrow_mut();  // 运行时 panic!
```

**Cell/RefCell 内存布局：**
```
RefCell<T> 结构：
┌──────────────┐
│ borrow: Cell │ ← 借用计数（运行时）
│   ├─ isize   │   正数：不可变借用数量
│   └─ 标志位  │   -1：可变借用
├──────────────┤
│ value: T     │ ← 实际数据
└──────────────┘

借用状态转换：
未借用(0) ─────> 不可变借用(n>0) ─────> 未借用(0)
    │                                        ↑
    └──> 可变借用(-1) ───────────────────────┘

特点：
- 编译时借用检查 → 运行时借用检查
- 有性能开销（原子操作）
- 可以在不可变引用内修改数据
```

## 3. 切片 (Slice) 底层原理

### 3.1 核心概念

**切片是对连续内存区域的引用视图，不拥有数据。**

### 3.2 字符串切片 (&str)

```rust
let s = String::from("hello world");
let hello = &s[0..5];
```

**内存布局：**
```
栈                    堆
s    ┌────┐          ┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
     │ptr │───────>  │h│e│l│l│o│ │w│o│r│l│d│
     ├────┤          └─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
     │len │           ↑       ↑
     ├────┤           │       │
     │cap │           │       │
     └────┘           │       │
                      │       │
hello ┌────┐          │       │
      │ptr │──────────┘       │
      ├────┤                  │
      │len │ = 5              │
      └────┘                  │
                              │
world ┌────┐                  │
      │ptr │──────────────────┘
      ├────┤
      │len │ = 5
      └────┘

切片 &str 结构（胖指针）：
- ptr: 8 字节（指向数据起始位置）
- len: 8 字节（切片长度）
总共：16 字节

特点：
1. 不拥有数据
2. 只是数据的"窗口"
3. 保证 UTF-8 边界安全
4. 零成本抽象（无运行时开销）
```

### 3.3 数组切片 (&[T])

```rust
let arr = [1, 2, 3, 4, 5];
let slice = &arr[1..4];
```

**内存布局：**
```
栈
arr   ┌───┬───┬───┬───┬───┐
      │ 1 │ 2 │ 3 │ 4 │ 5 │
      └───┴───┴───┴───┴───┘
       ↑   ↑           ↑
       │   │           │
       │   └───────┐   │
       │           │   │
slice ┌────┐       │   │
      │ptr │───────┘   │
      ├────┤           │
      │len │ = 3       │
      └────┘           │
                       │
full  ┌────┐           │
      │ptr │───────────┘
      ├────┤
      │len │ = 5
      └────┘

切片 &[T] 结构（胖指针）：
- ptr: 8 字节（指向第一个元素）
- len: 8 字节（元素数量）
总共：16 字节

访问开销：
- 边界检查：O(1)
- 元素访问：O(1)
- 迭代：零开销（优化后等同于指针操作）
```

### 3.4 切片与动态大小类型 (DST)

```
类型大小比较：
┌─────────────┬──────────┬────────────┐
│ 类型        │ 栈大小   │ 说明       │
├─────────────┼──────────┼────────────┤
│ &T          │  8字节   │ 瘦指针     │
│ &str        │ 16字节   │ 胖指针     │
│ &[T]        │ 16字节   │ 胖指针     │
│ String      │ 24字节   │ 拥有的数据 │
│ Vec<T>      │ 24字节   │ 拥有的数据 │
│ Box<[T]>    │ 16字节   │ 拥有的切片 │
└─────────────┴──────────┴────────────┘

DST (Dynamically Sized Type)：
- str：编译时大小未知
- [T]：编译时长度未知
- dyn Trait：大小和布局都未知

只能通过指针访问：
- &str, &[T], &dyn Trait（胖指针）
- Box<str>, Box<[T]>（拥有的胖指针）
```

### 3.5 切片的零成本抽象

**编译器优化：**

```rust
// 源代码
fn sum(slice: &[i32]) -> i32 {
    let mut total = 0;
    for &item in slice {
        total += item;
    }
    total
}

// 编译后（伪代码）
fn sum(ptr: *const i32, len: usize) -> i32 {
    let mut total = 0;
    let end = unsafe { ptr.add(len) };
    let mut current = ptr;
    
    while current < end {
        total += unsafe { *current };
        current = unsafe { current.add(1) };
    }
    total
}

// LLVM 优化后可能使用 SIMD 指令
// 性能等同于手写 C 代码
```

## 4. 生命周期 (Lifetime) 底层原理

### 4.1 核心概念

**生命周期是引用有效性的编译时标注，不影响运行时。**

### 4.2 生命周期的本质

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

**生命周期不是：**
- ❌ 运行时的概念
- ❌ 引用计数
- ❌ 垃圾回收标记

**生命周期是：**
- ✓ 编译时的静态分析
- ✓ 引用有效性的证明
- ✓ 零运行时开销
- ✓ 类型系统的一部分

### 4.3 生命周期推导

```rust
// 编译器看到的
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str

// 实际内存（运行时）
栈
x ┌────┐ ──> 某个字符串数据
  │ptr │
  ├────┤
  │len │
  └────┘

y ┌────┐ ──> 另一个字符串数据
  │ptr │
  ├────┤
  │len │
  └────┘

返回值（指向 x 或 y 的数据）
ret ┌────┐ ──> x 或 y 指向的数据
    │ptr │
    ├────┤
    │len │
    └────┘

生命周期保证：
返回的引用至少和 x、y 中较短的那个一样长
```

### 4.4 生命周期消除规则

**编译器自动推导的三条规则：**

```rust
// 规则 1：每个引用参数都有独立的生命周期
fn foo(x: &i32, y: &i32)
// 实际：fn foo<'a, 'b>(x: &'a i32, y: &'b i32)

// 规则 2：如果只有一个输入生命周期，赋给所有输出
fn foo(x: &i32) -> &i32
// 实际：fn foo<'a>(x: &'a i32) -> &'a i32

// 规则 3：如果有 &self 或 &mut self，其生命周期赋给所有输出
impl MyType {
    fn foo(&self, x: &i32) -> &i32
    // 实际：fn foo<'a, 'b>(&'a self, x: &'b i32) -> &'a i32
}
```

### 4.5 生命周期子类型化

```
生命周期的包含关系：
┌────────────────────────────┐ 'static
│ ┌────────────────────────┐ │ 'a
│ │ ┌────────────────────┐ │ │ 'b
│ │ │                    │ │ │
│ │ └────────────────────┘ │ │
│ └────────────────────────┘ │
└────────────────────────────┘

如果 'b: 'a（'b 至少和 'a 一样长）
那么 &'b T 可以用在需要 &'a T 的地方

协变规则：
&'a T      协变于 'a 和 T
&'a mut T  协变于 'a，对 T 不变
```

### 4.6 生命周期边界

```rust
// 结构体中的生命周期
struct Foo<'a> {
    x: &'a i32,
}

// 内存布局
┌──────────┐
│ Foo<'a>  │
│ ┌──────┐ │
│ │ ptr  │─┼──> i32 数据（必须活得比 Foo 久）
│ └──────┘ │
└──────────┘

// trait 约束
fn foo<'a, T>(x: &'a T)
where
    T: 'a,  // T 必须比 'a 活得久
{
    // ...
}
```

### 4.7 'static 生命周期

```rust
// 字符串字面量
let s: &'static str = "hello";

// 内存布局
程序二进制文件中：
┌────────────────────┐
│ .rodata 段         │
│ ┌────────────────┐ │
│ │ "hello\0"      │ │ ← 编译时写入
│ └────────────────┘ │
└────────────────────┘
         ↑
         │
栈      ┌┴───┐
s       │ptr │
        ├────┤
        │len │
        └────┘

'static 特点：
- 整个程序运行期间有效
- 存储在二进制文件中
- 不在堆上分配
- 零运行时成本
```

## 5. 内存布局与性能

### 5.1 完整的内存布局图

```
完整的 Rust 程序内存布局：

高地址
┌──────────────────┐
│   命令行参数      │
│   环境变量        │
├──────────────────┤
│                  │
│   栈 (Stack)     │ ← 栈指针向下增长
│   ↓              │   - 函数调用帧
│                  │   - 局部变量
│                  │   - 引用
│   ↑              │
├──────────────────┤
│   未使用空间      │
├──────────────────┤
│   ↓              │
│   堆 (Heap)      │ ← 堆指针向上增长
│   ↑              │   - Box, Vec, String
│                  │   - 动态分配
├──────────────────┤
│   BSS 段         │   未初始化全局变量
├──────────────────┤
│   数据段         │   已初始化全局/静态变量
├──────────────────┤
│   只读数据段     │   字符串字面量
│   (.rodata)      │   常量
├──────────────────┤
│   代码段         │   程序指令
│   (.text)        │   函数代码
└──────────────────┘
低地址
```

### 5.2 不同类型的性能特征

```rust
// 性能对比表
┌───────────────┬──────────┬──────────┬──────────┐
│ 操作          │ Copy     │ Move     │ Clone    │
├───────────────┼──────────┼──────────┼──────────┤
│ 栈复制        │ O(1)     │ O(1)     │ O(1)     │
│ 堆分配        │ 无       │ 无       │ O(n)     │
│ 原值是否有效  │ 是       │ 否       │ 是       │
│ 成本          │ 最低     │ 低       │ 高       │
└───────────────┴──────────┴──────────┴──────────┘

// 引用性能
┌───────────────┬──────────┬──────────┐
│ 操作          │ 不可变   │ 可变     │
├───────────────┼──────────┼──────────┤
│ 创建开销      │ 0        │ 0        │
│ 访问开销      │ 1次解引  │ 1次解引  │
│ 编译时检查    │ 是       │ 是       │
│ 运行时检查    │ 无       │ 无       │
└───────────────┴──────────┴──────────┘
```

### 5.3 零成本抽象的实现

```rust
// 高级 Rust 代码
let sum: i32 = vec![1, 2, 3, 4, 5]
    .iter()
    .filter(|&&x| x > 2)
    .map(|&x| x * 2)
    .sum();

// 编译后等价于（伪代码）
let sum: i32 = {
    let mut total = 0;
    let data = [1, 2, 3, 4, 5];
    for i in 0..5 {
        let x = data[i];
        if x > 2 {
            total += x * 2;
        }
    }
    total
};

// LLVM 优化后可能直接计算常量
const sum: i32 = 18;

零成本抽象的保证：
✓ 没有虚函数调用
✓ 没有动态分派（除非显式使用 dyn）
✓ 没有隐藏的内存分配
✓ 完全内联
✓ SIMD 优化
```

### 5.4 内存对齐

```rust
#[repr(C)]
struct Example {
    a: u8,      // 1 字节
    // 填充 7 字节
    b: u64,     // 8 字节
    c: u32,     // 4 字节
    // 填充 4 字节
}

// 内存布局（64位系统）
┌──┬──┬──┬──┬──┬──┬──┬──┐
│a │  padding (7 bytes) │ 偏移 0
├──┴──┴──┴──┴──┴──┴──┴──┤
│       b (8 bytes)      │ 偏移 8
├──┬──┬──┬──┬──┬──┬──┬──┤
│   c (4 bytes)  │padding│ 偏移 16
└──┴──┴──┴──┴──┴──┴──┴──┘

总大小：24 字节（不是 13 字节）

对齐规则：
- u8: 1 字节对齐
- u16: 2 字节对齐
- u32: 4 字节对齐
- u64: 8 字节对齐
- 结构体：按最大成员对齐
```

### 5.5 性能最佳实践

```rust
// ✅ 好：使用引用避免复制
fn process(data: &Vec<i32>) {
    for item in data {
        // ...
    }
}

// ❌ 差：不必要的克隆
fn process(data: Vec<i32>) {  // 移动了所有权
    for item in &data {
        // ...
    }
}

// ✅ 好：预分配容量
let mut vec = Vec::with_capacity(100);
for i in 0..100 {
    vec.push(i);  // 不会重新分配
}

// ❌ 差：频繁重新分配
let mut vec = Vec::new();
for i in 0..100 {
    vec.push(i);  // 可能多次重新分配
}

// ✅ 好：使用切片参数
fn sum(data: &[i32]) -> i32 {  // 接受 Vec, 数组, 切片
    data.iter().sum()
}

// ❌ 差：限制太多
fn sum(data: &Vec<i32>) -> i32 {  // 只接受 Vec
    data.iter().sum()
}
```

## 6. 总结

### 核心原理对比

```
┌──────────┬────────────┬────────────┬──────────┐
│ 特性     │ 编译时     │ 运行时     │ 性能     │
├──────────┼────────────┼────────────┼──────────┤
│ 所有权   │ 静态检查   │ 零开销     │ 最优     │
│ 借用     │ 静态检查   │ 零开销     │ 最优     │
│ 切片     │ 类型检查   │ 边界检查   │ 优秀     │
│ 生命周期 │ 静态分析   │ 零开销     │ 最优     │
│ RefCell  │ 部分检查   │ 运行时检查 │ 较好     │
└──────────┴────────────┴────────────┴──────────┘
```

### 关键要点

1. **所有权**：编译时的内存管理，零运行时开销
2. **借用**：安全的引用，编译器保证有效性
3. **切片**：胖指针，零成本的数据视图
4. **生命周期**：编译时标注，不影响运行时

### Rust 的独特优势

```
│          │    │ 静态分析 │     │          │
│ 安全     │    │          │     │ 不安全   │
│ 慢       │    │ 安全+快  │     │ 快       │
└──────────┘    └──────────┘     └──────────┘

Rust = 安全 + 性能 + 零成本抽象
```
