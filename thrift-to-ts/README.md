# thrift-to-ts

🦀 A Rust CLI tool to parse Thrift IDL files and generate TypeScript type definitions.

一个使用 Rust 开发的 CLI 工具，用于解析 Thrift IDL 文件并生成 TypeScript 类型定义。

## Features / 功能特性

- ✅ 完整的 Thrift IDL 词法分析 (Lexer)
- ✅ 完整的 Thrift IDL 语法解析 (Parser)
- ✅ 支持所有 Thrift 基本类型 (bool, byte, i16, i32, i64, double, string, binary)
- ✅ 支持容器类型 (list, set, map)
- ✅ 支持 struct, enum, union, exception, service 定义
- ✅ 支持 typedef, const 定义
- ✅ 支持 namespace, include 声明
- ✅ 生成现代 TypeScript 类型定义
- ✅ 支持批量处理目录中的所有 .thrift 文件

## Installation / 安装

### From Source / 从源码编译

```bash
# 克隆项目
git clone <repository-url>
cd thrift-to-ts

# 编译
cargo build --release

# 安装到系统
cargo install --path .
```

## Usage / 使用方法

### Basic Usage / 基本用法

```bash
# 转换单个文件
thrift-to-ts -i input.thrift -o output/

# 转换整个目录
thrift-to-ts -i ./thrift/ -o ./generated/

# 生成只读属性
thrift-to-ts -i input.thrift -o output/ --readonly

# 不添加 export 关键字
thrift-to-ts -i input.thrift -o output/ --no-export

# 详细输出
thrift-to-ts -i input.thrift -o output/ --verbose
```

### CLI Options / 命令行选项

| Option | Short | Description |
|--------|-------|-------------|
| `--input` | `-i` | 输入 Thrift 文件或目录 |
| `--output` | `-o` | 输出目录 |
| `--readonly` | | 生成只读属性 |
| `--no-export` | | 不添加 export 关键字 |
| `--verbose` | `-v` | 详细输出 |
| `--help` | `-h` | 显示帮助信息 |
| `--version` | `-V` | 显示版本信息 |

## Example / 示例

### Input (Thrift)

```thrift
namespace js user

enum UserStatus {
    ACTIVE = 1,
    INACTIVE = 2
}

struct User {
    1: required i64 id
    2: required string name
    3: optional string email
    4: required UserStatus status
    5: optional list<string> tags
    6: optional map<string, string> metadata
}

service UserService {
    User getUser(1: i64 id)
    void deleteUser(1: i64 id)
}
```

### Output (TypeScript)

```typescript
// This file is auto-generated by thrift-to-ts
// Do not edit manually

export enum UserStatus {
  ACTIVE = 1,
  INACTIVE = 2
}

export interface User {
  id: bigint;
  name: string;
  email?: string;
  status: UserStatus;
  tags?: string[];
  metadata?: Map<string, string>;
}

export interface UserService {
  getUser(id: bigint): Promise<User>;
  deleteUser(id: bigint): Promise<void>;
}
```

## Type Mapping / 类型映射

| Thrift Type | TypeScript Type |
|-------------|-----------------|
| `bool` | `boolean` |
| `byte` | `number` |
| `i16` | `number` |
| `i32` | `number` |
| `i64` | `bigint` |
| `double` | `number` |
| `string` | `string` |
| `binary` | `Uint8Array` |
| `void` | `void` |
| `list<T>` | `T[]` |
| `set<T>` | `Set<T>` |
| `map<K, V>` | `Map<K, V>` |

```

         │
         ▼

         │
         ▼

│     Parser      │  语法分析: Token 流 → AST

└────────┬────────┘
         │
         ▼
┌─────────────────┐

         │
         ▼

│  (codegen.rs)   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  TypeScript     │
│   .d.ts File    │
└─────────────────┘
```
